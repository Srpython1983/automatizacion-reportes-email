# 🤖 Automatización de Reportes por Email — Gratis

Script Python que lee tus archivos Excel o CSV y envía
reportes financieros automáticamente por email. Ideal para
empresas que necesitan enviar resúmenes diarios, semanales
o mensuales a su equipo sin hacerlo manualmente.

---

## ✅ ¿Qué hace este script?

- Lee cualquier archivo Excel o CSV automáticamente
- Genera un reporte con los datos clave
- Envía el reporte por email a uno o varios destinatarios
- Adjunta el archivo original al email
- Funciona con Gmail, Outlook y cualquier servidor SMTP

---

## 📁 Archivos disponibles

| Archivo | Descripción |
|---------|-------------|
| `enviar_reporte.py` | Script principal |
| `config.py` | Configuración de email y destinatarios |
| `datos-prueba.xlsx` | Archivo de prueba para testear |
| `instrucciones.md` | Guía paso a paso |

---

## 🚀 ¿Cómo usarlo?

1. Instala las dependencias: `pip install pandas openpyxl`
2. Configura tu email en `config.py`
3. Corre el script: `python enviar_reporte.py`
4. El reporte se envía automáticamente ✅
